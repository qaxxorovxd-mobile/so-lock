Features

Everything a lock should be.
Nothing it shouldn’t.

App Lock

4 or 6-digit PIN, or a full password. The lock screen is pre-loaded, so it appears the instant an app opens.

Biometric fallback

Fingerprint or face first. If the sensor fails or isn’t set up, your code always works.

Smart Lock

Lock only during work hours, never at home or on your own Wi‑Fi. Choose when apps re-lock.

Intruder Alert

After wrong attempts, the front camera — and optionally the back — takes a photo with the time and app.

Make it yours

Accent colours, gradient or photo backgrounds with blur and dim, three keypad styles, and shuffled keys so nobody can follow your fingers.

Feel every tap

Vibration from Off to Strong — separately for key presses, wrong codes and unlocks.

Fast, never in the way

Short hops — a gallery’s private album prompt, share sheets, pickers — never trap you in a lock loop.

Hard to brute-force

Growing lockouts after repeated wrong codes, and the lock screen never shows up in screenshots or recents.

Questions

Why does it need Accessibility access?

Android only lets an app know which other app is in front through Accessibility. So Lock listens to window changes only — it never reads text, taps or anything on your screen.

What exactly happens with a decoy code?

It’s accepted like a normal code, so the person holding your phone sees nothing unusual. Then the action you picked runs: lock the screen, go to the home screen, show a fake crash, or open the app while silently taking a photo.

Which file should I download?

The main button (arm64) fits almost every phone from the last several years and is the smallest. If it won’t install, use the 32-bit or Universal build.

I installed 1.0.0 — can I update?

1.0.0 was signed with a temporary key, so Android won’t update it in place. Uninstall 1.0.0 first, then install 1.1.0. Future versions will update normally.

Is there an iPhone version?

iOS doesn’t allow one app to lock other apps, so So Lock is Android-only for now.

Does the intruder photo work on every phone?

It works within Android’s camera rules. Some phones show a system “camera in use” indicator while the photo is taken, and it needs the camera permission.
